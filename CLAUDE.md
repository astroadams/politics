## Project Overview

This is a political data visualization project that analyzes U.S. presidential election trends from 1976-2020. The project creates interactive web applications using Dash to display:

1. **State-by-state election margins and partisan lean over time**
2. **Electoral vote cumulative distribution analysis** 
3. **Interactive choropleth maps** showing election results by year
4. **Precinct-level visualization** for detailed geographic analysis

## Main Applications

### `presidential_map.py` - Primary Dashboard
- **Purpose**: Main interactive dashboard showing presidential election trends
- **Features**: 
  - Choropleth maps with year slider and margin/lean toggle
  - Cumulative electoral vote distributions
  - State trend lines with hover interactions
- **Run with**: `python presidential_map.py`
- **Data source**: Processes `data/1976-2020-president.csv` and generates `data/margins.csv`

### Precinct Visualization Apps
- `precinct_level_visualization.py` - Basic precinct-level mapping
- `precinct_level_visualization_mapbox.py` - Enhanced version with Mapbox integration
- **Data source**: Uses GeoJSON files from `data/` directory
- **Run with**: `python precinct_level_visualization.py` or `python precinct_level_visualization_mapbox.py`

## Data Architecture

### Core Data Files
- `data/1976-2020-president.csv` - Raw presidential election results by state and year
- `data/margins.csv` - Processed file with calculated margins and partisan lean (generated by code)
- `electoral_vote_apportionment.csv` - Electoral vote counts by state over time
- `data/*.geojson` - Geographic boundary files for mapping

### Data Processing Pipeline
The `presidential_map.py` script contains data preprocessing logic that:
1. Calculates state-level vote margins from raw candidate totals
2. Computes partisan lean (state margin adjusted for national environment)
3. Links electoral vote counts from census data
4. Generates formatted text labels for visualizations

## Code Structure

### Key Functions in `presidential_map.py`
- `gen_map(year, radio)` - Generates choropleth map for given year and metric
- `gen_hist(GUI_year, radio)` - Creates electoral vote cumulative distribution
- `gen_state_trend_plot(radio, hover_data)` - Builds state trend line charts
- Dash callbacks handle interactivity between components

### Data Preparation Logic
The preprocessing section (lines 162-200) handles:
- Vote margin calculations: `(dem_votes/total - rep_votes/total) * 100`
- Partisan lean: `state_margin - national_margin`
- Electoral vote mapping from census years to election years
